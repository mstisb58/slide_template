# 🚀 インタラクティブ HTML スライド作成テンプレート

MarkdownとPlotlyを使って、**「3Dグラフが動く」「誰でも直感的に書ける」「サーバー不要・完全オフライン対応」** な次世代HTMLプレゼンテーションスライドを作成・配布できるテンプレート環境です。

## 🎯 目的別コマンド早見表

| あなたがやりたいこと | 実行するコマンド / アクション |
|---|---|
| **スライドをHTMLに変換したい** | `uv run build.py` *(または `python build.py`)* |
| **ビルドしてすぐブラウザで自動確認したい** | `uv run build.py --open` *(または `-o`)* |
| **スライドの内容を編集したい** | **[slide.md](file:///c:/Users/isobe/project/html/slide_template/slide.md)** をエディタで編集する |
| **グラフのデータを変えたい** | **`charts/sample_2d.html`** や **`sample_3d.html`** を編集する |
| **スライドの色やフォントを変えたい** | **[assets/css/theme-custom.css](file:///c:/Users/isobe/project/html/slide_template/assets/css/theme-custom.css)** を変更する *(F5で即時反映)* |

## 🔄 基本の作業フロー（3ステップ）

```text
[ 1. 編集する ]               [ 2. ビルドする ]                [ 3. 確認・配布する ]
 slide.md を書く   ──▶    uv run build.py      ──▶   slide_refered.html (確認用)
 charts/ を編集                                       slide_embed.html   (配布用)
```

1. **原稿を書く**: [slide.md](file:///c:/Users/isobe/project/html/slide_template/slide.md) をMarkdownで記述します。
2. **ビルドする**: ターミナルで `uv run build.py` を実行します。
3. **確認・配布する**:
   - **作成中の確認**: [slide_refered.html](file:///c:/Users/isobe/project/html/slide_template/slide_refered.html) を開く（画像やCSSの変更がブラウザF5で即時反映）。
   - **他者への配布**: [slide_embed.html](file:///c:/Users/isobe/project/html/slide_template/slide_embed.html) を送る（1ファイル完結・USBやメール添付で相手のPCでもそのまま動きます）。

## 📋 PowerPoint風 マスタースライド・レイアウトテンプレート集 (コピペ用)

PowerPointのマスタースライドのように、**「位置やサイズがCSSで事前定義されたテンプレート枠」**です。
以下のスニペットをコピーして [slide.md](file:///c:/Users/isobe/project/html/slide_template/slide.md) に貼り付け、タイトルやグラフパス、テキストを書き換えるだけで、**サイズ崩れのない美しいスライドが一発で完成**します。

> 💡 **統一された記法ルール（コロンとカッコの法則）**
> - **囲み枠ブロック（`:::` コロン3つ ＋ 最後に `:::` で閉じる）**: 間に文字や画像などを挟むコンテナ ➜ `::: layout(...)`, `::: card(...)`, `::: images(...)`
> - **単発部品（`::` コロン2つ ＋ 閉じタグ不要）**: その場にポンと埋め込む要素 ➜ `::include(...)`
> - **設定値（引数）はすべて関数のようにカッコ `(引数1, 引数2, ...)` で渡す**: `h=250px` や `w=80%` でサイズ指定可能

### 1. 表紙スライド (`::: layout(title)`)
日付・タイトル・サブタイトル・発表者名が四隅・中央に自動配置されます。
```markdown
---
::: layout(title)
20260903
# プレゼンテーションのタイトル
サブタイトル・研究テーマ
発表者 氏名
:::
```

---

### 2. 目次・アジェンダスライド (`::: layout(agenda, 1)`)
発表の現在地に合わせて光らせる章番号を指定できます（例: `layout(agenda, 2)` で2番目がハイライト）。
```markdown
---
## 目次

::: layout(agenda, 1)
1. 背景
2. 目的
3. 実験方法
4. 結果
5. 考察
:::
```

---

### 3. 1グラフ集中スライド (`::: layout(chart-focus)`)
画面中央に横幅いっぱいの**大型グラフ（最大化表示）**を配置し、下部に考察メモを添えるレイアウトです。
```markdown
---
::: layout(chart-focus)
## 3Dデータ分析結果 (本編)
多次元データの可視化（マウス操作で360度回転・ズーム・ホバーが可能）

::include("charts/sample_3d.html")::
::: memo
- クラスタごとの空間的広がりと特異値の分布を直感的に把握可能。
- ここに要約や考察ポイントを箇条書きで記入します。
:::
:::
```

## 📝 目的別・個別パーツ記法リファレンス (パーツ単位)

### ① スライドを分けたい（ページ送り）
- **`---`** （ハイフン3つ）: **横送り** ➜ 次の章や新しいトピックへ（`→` キー）
- **`--`** （ハイフン2つ）: **縦送り** ➜ 詳細データや補足資料へ（`↓` キー）

---

### ② 表紙スライドを作りたい
1行目に日付、`#` にタイトル、その下にサブタイトル、最後に発表者名を書くと自動で四隅・中央に配置されます。
```markdown
::: title
20260903
<!-- タイトル -->
# NIR-HSIを用いた毛髪診断システムの開発
<!-- サブタイトル -->
毛髪でひも解く漢方体質分類
<!-- 発表者 -->
礒辺真人
:::
```

---

### ③ 目次を作りたい（自由なステップハイライト設定）
`::: agenda` の後ろにオプションを付けることで、発表の流れに合わせて**光らせる項目・順番を自由自在に指定**できます。

```markdown
## 目次

::: agenda:3
1. プロジェクトの背景と課題
2. 漢方体質アンケート
3. アンケート結果解析
4. 毛髪とアンケート
5. 今後の展開と課題
:::
```

| 指定方法 | 実際のハイライトの動き |
|---|---|
| **`::: agenda:3`** | 最初は全体 ➜ **03だけ光る（他は薄くなる）** ➜ 次のスライドへ |
| **`::: agenda:1,3`** | 最初は全体 ➜ **01** ➜ **03** ➜ 次のスライドへ |
| **`::: agenda`** (または `:auto`) | 最初は全体 ➜ **01** ➜ **02** ➜ **03** ... （全項目順番） |
| **`::: agenda:none`** | **ステップなし**（最初から最後まで全体が明るい静止目次） |
| **`::: agenda:fixed:2`** | **最初から02が固定で光っている**（各章の扉スライド用） |

### ④ 汎用 N×M グリッド分割 (`::: grid(col=N, row=M)`)

画面の余白を **列数 (`col`) と 行数 (`row`)** で自在に均等分割し、各マス（セル）にグラフ・画像・カードを自動フィットして配置できます。
マス同士の区切りには `::: split` を挟みます。

```markdown
<!-- 例: 3列 × 2行 (6マス) のダッシュボード配置 -->
::: grid(col=3, row=2, h=480px)
::include("charts/chart1.html")::
::: split
::include("charts/chart2.html")::
::: split
![画像](graph/cube.png)
::: split
::: card(yellow)
下段左の解説カード
:::
::: split
<!-- 空白マスにしたい場合はコメントのみ -->
::: split
::: card(blue)
下段右のまとめ
:::
:::
```

#### 基本パターン
| 指定方法 | 動作 |
|---|---|
| **`::: grid(col=2, row=1)`** | 左右に均等 2分割（50% : 50%） |
| **`::: grid(col=3, row=1)`** | 横に均等 3分割（33% : 33% : 33%） |
| **`::: grid(col=2, row=2)`** | 田の字型 4分割ダッシュボード |
| **`::: grid(col=2:1, row=1)`** | **左右の幅比率を指定**（左2/3 : 右1/3） |
| **`::: grid(col=1:2:1, row=1)`** | 中央が広い 3分割（左25% : 中50% : 右25%） |
| **`::: grid(col=2, row=2:1)`** | **上下の高さ比率を指定**（上2/3 : 下1/3） |

※ 高さは指定なし（デフォルト）で**スライドの下端まで自動でめいっぱい伸びます**（`h=480px` などで固定も可能）。行数は厳格に **`row`**（行）です。

### ⑤ カード枠 & 色分け（`::: card(色名)`）
```markdown
::: grid(col=3, row=1)
::: card(yellow)
**気：生命エネルギー**
- 気虚、気滞、気逆
:::
::: split
::: card(red)
**血：血液・ホルモン**
- 血虚、瘀血
:::
::: split
::: card(blue)
**水：水分代謝**
- 水滞、水毒
:::
:::
```
- **`::: card`**: 基本カード（グレー淡色）
- **`::: card(blue)`**: 淡いロイヤルブルーカード
- **`::: card(red)`**: 淡いピンク/レッドカード
- **`::: card(yellow)`**: 淡いイエローカード
- **`::: card(gold)`**: 濃いめゴールドカード
- **`::: card(bg="#f0fdf4")`**: 任意背景色の直接指定

### ⑥ 画像の横並び（`::: images(枚数, h=高さ)`）
余計な枠影なしで、背景の上にスッキリ左右配置します。
```markdown
::: images(2, h=280px)
![画像1の説明](graph/cube.png)
![画像2の説明](graph/taishitu.png)
:::
```
- **`::: images(2, h=280px)`**: 2枚横並び（高さを280pxに自動統一）
- **`::: images(3, h=240px)`**: 3枚横並び（高さを240pxに自動統一）

### ⑧ 3Dグラフ・外部HTMLの埋め込み（サイズ指定対応）
HTMLファイル（Plotlyのグラフ等）をスライド内に埋め込みます。
ファイルパスの後ろにコロン `:` でサイズ（`40%` や `180px`）を指定して縮小表示も可能です。

```markdown
<!-- 基本: 枠に合わせて100%表示（レイアウトテンプレート内などで使用） -->
::include(charts/sample_3d.html)::

<!-- 高さ指定 (40%): カード内などでテキストの下にコンパクトに配置したい時 -->
::include(graph/outputs/aic.html:40%)::

<!-- 高さ指定 (ピクセル指定): 高さを固定したい時 -->
::include(graph/outputs/aic.html:180px)::

<!-- 幅と高さを両方指定 -->
::include(graph/outputs/aic.html:h=180px,w=80%)::
```

## ⌨️ プレゼン時のキーボード操作

| キー | 動作 |
|---|---|
| **`→` / `Space`** | 次のスライド（または次のステップ）へ進む |
| **`←`** | 前のスライドへ戻る |
| **`↓` / `↑`** | 縦送りスライド（詳細データ・補足資料）へ進む / 戻る |
| **`F` / `F11`** | **全画面表示** の切り替え |
| **`ESC` / `O`** | **全スライド一覧（タイルモーダル）** の開閉 |
