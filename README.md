# 🚀 HTMLスライド作成テンプレート

MarkdownとPlotlyを使って、**「3Dグラフが動く」「サーバー不要・オフラインで動く」** 次世代HTMLスライドを作成・配布できる環境です。

---

## 🎯 目的別コマンド早見表

| あなたがやりたいこと | 実行するコマンド / アクション |
|---|---|
| **スライドをHTMLに変換したい** | `uv run build.py` *(または `python3.12 build.py`)* |
| **ビルドしてすぐブラウザで確認したい** | `uv run build.py -o refered`<br>*(または `slide_refered.html` をダブルクリック)* |
| **配布用ファイルを開いて確認したい** | `uv run build.py -o embed`<br>*(または `slide_embed.html` をダブルクリック)* |
| **スライドの内容を編集したい** | **`slide.md`** をエディタで開いて編集する |
| **グラフのデータを変えたい** | **`charts/sample_2d.html`** や **`sample_3d.html`** を編集する |
| **スライドの色やフォントを変えたい** | **`assets/css/theme-custom.css`** を変更する *(再ビルド不要・ブラウザF5で即時反映)* |

## 🔄 基本の作業フロー（3ステップ）

```text
[ 1. 編集する ]               [ 2. ビルドする ]                [ 3. 確認・配布する ]
 slide.md を書く   ──▶    uv run build.py      ──▶   slide_refered.html (確認用)
 charts/ を編集                                       slide_embed.html   (配布用)
```

1. **原稿を書く**: [slide.md](file:///c:/Users/isobe/project/html/slide_template/slide.md) をMarkdownで記述します。
2. **ビルドする**: ターミナルで `uv run build.py` を実行します。
3. **確認・配布する**:
   - **作成中の確認**: [slide_refered.html](file:///c:/Users/isobe/project/html/slide_template/slide_refered.html) を開く（画像やCSSの変更がF5で即反映）。
   - **他者への配布**: [slide_embed.html](file:///c:/Users/isobe/project/html/slide_template/slide_embed.html) を送る（1ファイル完結・ネット不要）。

## 📝 目的別・Markdown書き方リファレンス (コピペ用)

### ① スライドを分けたい（ページ送り）
- **`---`** （ハイフン3つ）: **横送り** ➜ 次の章や新しいトピックへ（`→` キー）
- **`--`** （ハイフン2つ）: **縦送り** ➜ 詳細データや補足資料へ（`↓` キー）

---

### ② 表紙スライドを作りたい
1行目に日付、`#` にタイトル、その下にサブタイトル、最後に発表者名を書くと自動で四隅・中央に配置されます（タイトル内 `<br>` で改行可能）。
```markdown
::: title
<!-- 左上: 日付 -->
2026年3月
<!-- 画面中央: タイトル -->
# Dynamic Hair<br>Vibration Analysis
<!-- 中央下部: サブタイトル -->
3D Visualization and Quantitative Analysis
<!-- 右下: 発表者名 -->
礒辺真人
:::
```

---

### ③ 目次を作りたい（自由なステップハイライト設定）
`::: agenda` の後ろにオプションを付けることで、発表の流れに合わせて**光らせる項目・順番を自由自在に指定**できます。

```markdown
## 目次

::: agenda:3
1. プロジェクトの背景と課題
2. 提案内容と3Dデータ可視化
3. 高度な表現力（数式・コード・表）
4. 今後の展開とロードマップ
:::
```

| 指定方法 | 実際のハイライトの動き |
|---|---|
| **`::: agenda:3`** | 最初は全体 ➜ **03だけ光る（他は薄くなる）** ➜ 次のスライドへ |
| **`::: agenda:1,3`** | 最初は全体 ➜ **01** ➜ **03** ➜ 次のスライドへ |
| **`::: agenda:1-3`** | 最初は全体 ➜ **01** ➜ **02** ➜ **03** ➜ 次のスライドへ |
| **`::: agenda`** (または `:auto`) | 最初は全体 ➜ **01** ➜ **02** ➜ **03** ➜ **04** （全項目順番） |
| **`::: agenda:none`** (または `:static`) | **ステップなし**（最初から最後まで全体が明るい静止目次） |
| **`::: agenda:fixed:2`** | **最初から02が固定で光っている**（各章の扉スライド用） |

### ④ 箇条書きを1行ずつアニメーション表示したい
`Space` や `→` を押すごとに、1行ずつフェードインします。
```markdown
## 重要な3つのポイント

::: step
- 1番目のポイント（クリックで出現）
- 2番目のポイント（さらにクリックで出現）
- 3番目の結論（最後にフェードイン）
:::
```

## ⌨️ プレゼン本番のキーボード操作

| キー | 動作 |
|---|---|
| `Space` / `→` | 次のスライド（または次のステップ）へ進む |
| `←` | 前のスライドへ戻る |
| `↓` / `↑` | 縦送りスライド（詳細・補足）の上下移動 |
| 画面左下ボタン / `ESC` / `O` | **📑 全スライドのタイル一覧表示（カードビュー）** |
| 画面左下ボタン / `F` / `F11` | **⛶ 全画面表示 (Fullscreen: ブラウザの帯が完全に消えます)** |
